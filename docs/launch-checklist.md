# Launch checklist

- [ ] Confirm preferred public name and professional biography.
- [ ] Verify credential names, institutions, dates, employers, and CV.
- [ ] Review project ownership, current status, screenshots, repository access, and privacy.
- [ ] Verify research/publication metadata and citation style.
- [ ] Add public email and social links only after confirmation.
- [ ] Select and configure final domain; set `NEXT_PUBLIC_SITE_URL`.
- [ ] Create favicon, wordmark, and OG image.
- [ ] Review Arabic and Amharic typography before enabling language routes.
- [ ] Add full track pages and media metadata.
- [ ] Implement contact form with spam controls and privacy notice.
- [ ] Run accessibility review against WCAG 2.2 AA.
- [ ] Run npm install, lint, typecheck, and production build locally.
- [ ] Deploy a preview to Netlify and verify routes, metadata, images, and forms.
- [ ] Confirm child-directed content classification and safeguarding review before publishing.
- [ ] Verify religious sources and scholarly review where needed.
